# Go GUI Calculator

A cross-platform desktop GUI calculator application written in Go using the [Fyne v2](https://fyne.io/) GUI library.

## Quick Start

### Prerequisites
- Go 1.22+ installed
- On Linux: C compiler and graphics libraries (`gcc`, `libgl1-mesa-dev`, `xorg-dev`)

### Run directly
```bash
go run .
```

### Build binary
```bash
go build -o calculator .
./calculator
```
